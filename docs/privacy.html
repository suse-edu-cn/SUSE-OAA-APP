概述

青蟹（Project OAA，以下简称"本应用"）由四川轻化工大学开放原子开源协会（SUSE OAA）项目部开发和维护， 是一款帮助在校学生更方便地查看课表、成绩、考试安排等教务信息的开源辅助工具。

本应用的开发团队不会收集、留存或用于分析你的个人信息，也不会将任何信息出售或提供给无关的第三方。 本页说明本应用在实现各项功能时，会如何处理你的信息。

我们如何处理你的信息

教务 / 签到账号信息

当你使用登录、查询课表成绩、打卡签到等功能时，本应用需要将你的学号与密码等必要信息，直接发送给学校官方教务系统或 SUSE OAA 自建的打卡 / 后端服务，以代替你完成对应的操作。这些信息仅用于完成你主动发起的当次请求， 开发团队不会将其另作他用，也不会在自己的服务器上长期留存你的账号密码。

本地缓存数据

为了支持离线查看和更流畅的体验，课表、成绩、考试安排等数据会缓存在你设备本地的数据库中； 登录凭证（Token）也仅保存在本机安全存储区域。这些数据不会被上传至开发团队的服务器，卸载应用或清除应用数据即会一并删除。

验证码识别

登录时的图形验证码识别（ML Kit / ONNX Runtime / Vision Framework）完全在你的设备本地完成推理， 验证码图片不会被上传到任何服务器。

数据存储与安全

  • 登录密码在传输前使用 RSA 公钥加密，所有网络请求均通过 HTTPS 加密传输；
  • 教务系统、打卡系统、扫码签到分别使用相互隔离的会话（Cookie），互不干扰；
  • 登录 Token 使用系统级安全存储（DataStore）保存在本机；
  • 本应用完全开源，代码可在 GitHub 上自由审查。

第三方服务

本应用不集成任何广告 SDK，也不使用第三方用户行为分析或追踪服务。应用会在启动时向 GitHub 发起一次公开的版本号查询请求，用于检查是否有新版本可用，该请求不包含任何与你身份相关的信息。

本应用对接的学校教务系统、OAA 打卡系统等均为完成教务相关功能所必需，它们各自的隐私与数据处理方式由相应的系统或组织负责，不在本政策约束范围内。

你的权利与选择

  • 你可以随时在应用内退出登录，本机保存的账号信息与缓存数据会被清除；
  • 卸载应用会删除本机存储的全部本地数据；
  • 你的学校教务账号数据由学校统一管理，如需查询、更正或删除相关数据，请联系学校教务处，本应用无法代为处理。

政策更新

如果本应用的功能或数据处理方式发生变化，我们会更新本页面内容，并在页面顶部标注最新的更新日期。建议你在使用本应用前留意本页面是否有更新。
